Invités à placer

Plan de Table

Un dîner, des tables rondes, et des invités qui s'aiment… ou pas. Faites le meilleur plan de table possible pour maximiser l'ambiance !

  • Glissez-déposez les têtes des invités sur les sièges des tables (ou cliquez : sélectionner un invité, puis un siège).
  • Chaque invité a sa tête, sur le schéma comme sur les sièges.
  • Sur le schéma, chaque lien est vert (amitié) ou rouge (hostilité) : plus le trait est épais, plus le lien est fort. Cliquez sur une tête pour surligner ses relations.
  • Deux amis à la même table : points positifs. Deux ennemis à la même table : gros malus, le lien passe au doré.
  • Deux personnes côte à côte sur une table ronde se parlent plus : bonus ou malus amplifié.
  • Atteignez l'objectif d'ambiance (trait noir sur la jauge) pour réussir le niveau et débloquer le suivant.
